AudioLib Explorer 达芬奇整合版
==============================

这是在 AudioLib Explorer v1.0.2 源码基础上增加功能后的版本。

新增功能
--------
把音效一键插入 DaVinci Resolve 当前时间线的播放头位置。

两个入口，随便用哪个：
  · 右侧「声音详情」面板 → 时长/采样率下方的主按钮「导入到达芬奇时间线」
  · 在结果列表里右键 → 「导入到达芬奇时间线」

插入逻辑：
  · 自动挑一条在播放头位置本来就空着的音频轨，不会覆盖已有内容
  · 所有音频轨在播放头处都被占用时，才新建一条音频轨
  · 反复插入不会把音轨堆成一长串


使用前提
--------
1. DaVinci Resolve 正在运行，并且已经打开一个项目和一条时间线。

2. 本机装有 Python 3.8 以上。
   - Windows：从 python.org 安装，安装时勾选 Add Python to PATH。
     装好后在命令提示符里执行 python --version 应能显示版本号。
   - macOS：终端执行 xcode-select --install 即可获得系统自带 python3。

3. 达芬奇里开启了外部脚本。
   Preferences → System → General → External scripting using
   设为 Local（同一台机器）或 Network。

   Resolve 免费版不支持脚本接口，必须是 Studio 版。

4. 音频文件本身还在原位置。如果记录显示为「缺失」，先修复文件引用再插入。


第一次点没反应怎么办
--------------------
状态栏会依次显示：
  「正在把声音送进达芬奇时间线…」 → 然后给出结果或原因。

常见提示与处理：
  · 没有找到 Python 3        → 按上面第 2 条装 Python
  · 没有连上 DaVinci Resolve → 先启动 Resolve，并确认 External scripting 已开启
  · 达芬奇里没有打开的项目   → 打开一个项目
  · 当前项目没有激活的时间线 → 双击打开一条时间线
  · 找不到达芬奇脚本目录     → Resolve 安装不完整，或装在了非默认位置


关于自动更新
------------
本版已永久关闭更新检查（设置页会显示「此安装已关闭更新检查」）。

原因：官方发布包会整体替换可执行文件，一更新达芬奇功能就没了。
想升级原版功能时，请重新获取新一版的整合包，不要用官方更新。
